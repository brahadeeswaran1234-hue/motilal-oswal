3. Technology Stack & Architectural Decisions
Technology Component Scope Strategic Rationale & Performance Benefit
Semantic HTML5 Single Page Application (index.html) Delivers near-instant initial render. Semantic nodes (<header>, <main>, <section>, <footer>) maximize organic SEO search engine crawl efficiency.
Vanilla CSS3 (Modular) 27 Modular Stylesheets (assets/css/) Zero CSS-in-JS compilation overhead. Eliminates heavy Tailwind / Bootstrap bundle weight while allowing granular caching of specific component styles.
Vanilla JavaScript (ES6+) Core Client Logic (assets/js/main.js ~26KB) Zero multi-megabyte React/Vue runtime hydration penalty. Ensures ultra-fast Time To Interactive (TTI) on mobile devices, handling form checks, modals, and event tracking natively.
Vercel Edge Platform Global Edge Network & CI/CD Hosting Automated deployments directly linked to GitHub main branch. Provides enterprise-grade Edge caching, automated HTTPS, and microsecond CDN routing.
Google Analytics 4 Measurement ID: G-T4DXB88B0F Dynamic non-render-blocking injection. Tracks acquisition funnels and fires custom partner_click events on every CTA interaction.
PWA Manifest Installable Web App (manifest.json) Enables "Add to Home Screen" on Android and iOS devices, providing native-like app launch without app store friction or distribution overhead.
JSON-LD Structured Data Schema.org Microdata in <head> Implements WebSite, Organization, and FAQPage schemas to secure Google rich snippet features and enhanced SERP authority.
4. Security Hardening & Performance Benchmarks

Hardened HTTP Headers (via vercel.json)

  • X-Content-Type-Options: nosniff (MIME protection)
  • X-Frame-Options: SAMEORIGIN (Clickjacking defense)
  • Strict-Transport-Security: max-age=63072000; preload
  • Referrer-Policy: strict-origin-when-cross-origin
  • Permissions-Policy: geolocation=(), camera=()

Performance & Core Web Vitals

  • Cumulative Layout Shift (CLS = 0): Explicit image width/height applied across all visual assets.
  • Asset Caching: 1-Year immutable caching (max-age=31536000).
  • Preconnected Fonts: Google Fonts loaded via non-blocking links.
  • Deferred Script Loading: Main JS executes asynchronously.
